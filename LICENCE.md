## 🧩 About

**Sea of Thieves Hack Menu** is a curated list of Sea of Thieves open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar map, item tracker
- **Quality-of-Life Helpers** — loot filter, HUD notes, config manager
- **Research Notes** — sailing routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Map Radar — visualize nearby islands and ships
- Loot Tracker — highlight nearby treasure
- Voyage Notes — record and review sailing runs
- Speed Adjust — adjust playback for study (0.1x to 5x)

### Wallhack
- Outfit Catalog — browse cosmetics and colors
- Custom Skin Notes — organize player appearance
- HUD Enhancements — improved visibility of resources

### Aimbot
- Practice Mode Notes — segment study on any route
- Wind Control — manually adjust wind direction for study
- Jump Buffer Notes — chain complex maneuvers in the editor
